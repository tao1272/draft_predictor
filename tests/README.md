# Tests

Add automated tests here as project functionality is implemented. Use
`test_*.py` or `*_test.py` filenames so pytest and CI can discover them.

Install the development dependencies from the repository root with
`python -m pip install -e ".[dev]"`, then run `python -m pytest`.

The initial scaffold has no behavioral tests. CI checks installation, formatting,
and packaging now and will run pytest automatically once test files are present.
